# M4 EGT UI — Wireframe & Current Flow

> Report generated by capturing every screen from the simulator
> (`develop @ 57f72a7`, 800×480). It documents **how each screen looks today**
> and **how they connect** in the app flow.
>
> - **Interactive flow** (clickable frames + wires): open [`wireframe.html`](wireframe.html) in a browser
> - All screens at a glance: [`wireframe-all.png`](wireframe-all.png)
> - Full-res individual PNGs: [`screens/`](screens/)
> - Labelled thumbnails: [`thumbs/`](thumbs/)
>
> Note: the rendered font is DejaVu (fallback) — the design font Gothic A1 is
> still pending installation at the Linux level (doubt D1). On the final device
> the text will be slightly narrower.

## Notes

- **Font**: all text renders with DejaVu (fallback). The design font
  **Gothic A1** is pending installation at the Linux level (doubt D1); with it
  the text will be narrower and truer to Figma.
- **Figma parity status**: these screens went through the parity sweep (see
  [`../figma-parity/`](../figma-parity/)) — they match the design except for the
  font and the open product decisions (D2-D7).
- **How to reproduce a screen**: `EGT_START_SCREEN=<name> ./build-x86/egt-app`
  (treatment states: `EGT_START_SCREEN=treatment EGT_MOCK_TREATMENT=<state>`).
